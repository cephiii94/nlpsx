# NLPSX Project History

## Origin

NLPSX was conceived on 12 June 2026 in Indonesia.

The initial idea was to create a programming language that focuses on meaning rather than mechanism, allowing developers to write code closer to how humans think.

Initial architecture:

File .nlpsx
↓
Lexer
↓
Parser
↓
AST
↓
Interpreter
↓
Output

Tagline:

Code the Way You Think.
