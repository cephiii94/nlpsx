# NLPSX

**Code the Way You Think.**

NLPSX adalah eksperimen bahasa pemrograman yang dirancang agar lebih dekat dengan cara manusia berpikir, tetapi tetap memiliki struktur bahasa pemrograman yang jelas.

VISI :
NLPSX adalah bahasa pemrograman yang menuliskan makna, bukan mekanisme.
